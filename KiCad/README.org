Open DriveShield_v1_8.kicad_pro in KiCad 10.0.1 or later.

This is an inspection/migration copy of the unchanged upstream EasyEDA design, not a fabrication release. Read ../Design/DriveShield_pinout.org (or its HTML export) before using it.

* Validation
- Schematic loaded in the native editor and exported to PDF and XML netlist.
- PCB imported with the native EasyEDA Standard importer; importer reports zero errors/warnings.
- All 301 source pad instances, including standalone pads, retain their pad number and net name in the imported PCB (pad-net-audit.json).
